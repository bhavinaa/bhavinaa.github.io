The Keepers

React Native Firebase Firestore
View on GitHub

"Lost time is never found again." — Benjamin Franklin

The problem

Students struggle to stay focused and organized, and most task managers either dump every feature on you at once or don't give you a reason to actually open the app twice. Sahana and I built The Keepers to close that gap — task management with enough gamification to make staying on top of deadlines feel less like a chore.

What we built

The app lets users organize tasks into categories with checklists, run focus sessions with a built-in Pomodoro timer, and sync tasks to their calendar. On top of the core task layer we added a reward system — completing tasks earns coins and gems — and a goal-setting feature built around the SMART (Specific, Measurable, Achievable, Relevant, Time-bound) framework, letting users set and track daily, weekly, and semester-long goals.

The stack is React Native for a cross-platform mobile app, with Firebase Authentication for sign-up/login/password reset and Firestore as the real-time backend for tasks, sessions, and profile data. We built this for NUS Orbital, a self-directed software development programme where teams propose their own scope and target an achievement tier — we aimed for Apollo 11, which meant scoping the reward system and SMART goal tracking as our differentiating extension features on top of a solid core.

What I learned

  • Working as a two-person team on a semester-long build meant actually dividing ownership cleanly — I focused on the Firebase integration and task/checklist logic while Sahana led the timer and rewards system, and we had to keep our interfaces to each other's code stable as both moved fast.
  • Gamification only works if it's attached to something users already want to do — the reward system mattered because it sat on top of task completion, not instead of it.
  • Firestore's real-time sync is powerful but you still have to think carefully about read/write costs once you're updating state on every timer tick.
The features that stuck weren't the ones we thought were clever — they were the ones that made someone open the app a second day in a row.
