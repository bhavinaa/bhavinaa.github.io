Personal project

Bhavs

Task management CLI tool
View on GitHub

"Lost time is never found again." — Benjamin Franklin

The problem

Most task management tools solve for feature breadth — labels, boards, integrations, notifications — when what I actually wanted most of the time was to add a task, see what's due, and get back to work. Bhavs is my answer to that: a task manager that does a small number of things well instead of a large number of things adequately.

What it does

  • Add and manage tasks with minimal friction
  • Track deadlines so nothing important slips
  • Set reminders for upcoming tasks
  • Filter tasks by priority, due date, or completion status

The whole thing is built around three priorities: simplicity (no unnecessary complexity), focus (organize tasks without piling on distractions), and speed (lightweight enough to open and close in seconds).

What I learned

  • Constraint is a feature — deliberately keeping the scope small made the tool something I actually keep using, unlike heavier tools I'd tried and abandoned.
  • Text-based interfaces force you to think hard about information density, since you don't have visual layout to lean on to communicate priority or status.
  • Building a tool for yourself first is a good filter — if I wasn't reaching for it daily, that was a signal something was off with the design, not just the marketing.
The best productivity tool is the one you don't have to think about using.
